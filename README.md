# 校园综合服务平台 v2.1

原生 HTML、CSS、JavaScript 实现的校园服务交互应用，保留深蓝、米白的手机端视觉。支持闲置、失物、活动、互助、问卷、随拍、地图与个人中心。运行时无框架、无后端、无线上支付和实时聊天。

所有业务操作只保存在当前浏览器和当前站点的数据空间中。它们不会发送到其他用户、其他设备或远程服务器。“联系申请”和“认领申请”的本机记录不等于对方已收到通知；失物必须经核验后确认完成。

## 启动

需要 Node.js 22 或更新版本。运行应用不需要安装依赖：

```sh
npm run dev
```

浏览器访问 `http://localhost:4173`。服务器只监听本机地址，可通过 `PORT` 环境变量更换端口。也可以直接用静态托管平台提供整个目录，不需要构建步骤。直接打开 HTML 可以使用多数功能，但为了避免 `file:` 存储行为的浏览器差异，建议用 HTTP 服务验收。

## 数据与兼容

- 新存档采用版本 1 的统一结构。初始演示数据位于脚本中，用户发布、覆盖记录、收藏、参与、消息、回答、照片、资料和积分流水独立持久化。
- 首次读取时迁移旧版 `campus_user` 与 `campus_snaps`。迁移不会主动删除旧键，保存成功后刷新可以继续使用新数据。
- 旧版商品发布、报名、问卷、收藏和消息已读仅存在运行内存中，没有磁盘数据，无法事后恢复。
- 保存采用先校验、持久化成功后才更新内存的方式。存储容量不足时不显示成功、不清空表单、不提交部分业务数据。
- 每次保存尝试保留上次有效快照。发现损坏数据时尝试备份恢复，并尽可能保留损坏原文。检测到更高版本时只读预览，不覆盖新版本数据。
- 多标签页检测到写入冲突时拒绝覆盖，提示刷新。关闭浏览器的存储权限时只读预览。
- “我的”底部提供重置入口，二次确认后清除本应用新旧存档并恢复演示数据，不清除其他站点或其他应用的数据。
- 图片压缩后仍会占用浏览器容量，适合少量本机体验；容量不足时会给出提示，正式跨设备图片服务不在本版范围。

## 主要操作

- 五种发布结果：闲置、失物、活动、搭子/技能互助、问卷都会进入列表、我的发布和消息。作者可以编辑、下架、重新发布、标记完成。
- 联系请求、活动报名、互助申请、失物核验申请、问卷提交进入“我的参与”。取消报名撤回对应积分；再次报名不会重复领取奖励。
- 已有回答的问卷不允许修改题目，允许修改标题、说明。支持单选、多选、填空、必填校验、每浏览器一次提交和本机结果统计。
- 初始问卷补充为 3 道可填写的示例题；示例中的历史参与人数不伪装成实际回答，不进入本机结果统计。
- 非公开失物特征只出现在作者管理界面。申请人填写自己的特征、时间、地点后保持待核验。核验和交接是独立步骤。
- 地图标签定位到平面图近似坐标，发布页可点选校园地点；不提供 GPS 或路线规划。
- 校徽五连击与纸飞机入口继续保留。

## 积分

初始 320 分保留为一条明确的迁移基数流水；首次发布 +10、完善资料 +10、首次报名活动 +10、首次提交每份问卷 +20、作者确认完成内容 +20、确认找回/归还失物 +50。每条奖励都有唯一来源，重复点击不重复加分。取消报名会撤回首次报名积分。徽章根据当前发布、完成记录和积分计算。

这套规则服务于本机演示，不代表真实信用认证或可兑换资产。

## 测试

不需要第三方库的核心测试：

```sh
npm test
```

浏览器测试使用 Playwright。首次在普通开发环境运行：

```sh
npm install
npx playwright install chromium
npm run dev
```

另一个终端运行：

```sh
npm run test:browser
```

测试默认访问本机 4173 端口，可用 `TEST_URL` 改变目标；可用 `CHROME_PATH` 指定已有 Chrome，也可用 `PLAYWRIGHT_MODULE` 指定现有 Playwright 包路径。测试使用隔离的浏览器上下文，不读取真实浏览器中的用户数据。截图和验收报告写入被 Git 忽略的 `test-results/`。

当前测试覆盖：五类发布刷新、详情深链接、前进后退、收藏、消息、报名、积分、认领、问卷、迁移、损坏恢复、容量回滚、多标签页冲突、输入转义、图片上传、触控横竖屏和重置。详细批次记录见 `UPGRADE-v2.1.md`。
